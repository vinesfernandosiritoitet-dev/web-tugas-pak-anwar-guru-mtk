Ringkasan Materi Fungsi

Konsep-konsep utama yang perlu dikuasai

1. Fungsi Linear: f(x) = ax + b

Grafik berupa garis lurus dengan kemiringan gradien a dan titik potong sumbu Y di (0, b).

2. Fungsi Kuadrat: f(x) = ax² + bx + c

Grafik berbentuk parabola. Titik puncak berada di koordinat (-b/2a, -D/4a).

3. Komposisi Fungsi: (f ∘ g)(x) = f(g(x))

Memasukkan seluruh hasil ekspresi fungsi g(x) ke dalam variabel x pada fungsi f(x).

Latihan Soal Mandiri

Buka pembahasan untuk mencocokkan jawabanmu

1. Diketahui f(x) = 2x + 3 dan g(x) = x² - 1. Tentukan (f ∘ g)(2).

Jawaban:
Hitung g(2) = 2² - 1 = 3.
Maka f(g(2)) = f(3) = 2(3) + 3 = 9.

2. Cari titik puncak parabola dari fungsi f(x) = x² - 4x + 3.

Jawaban:
Xp = -b/(2a) = -(-4)/2 = 2.
Yp = f(2) = 2² - 4(2) + 3 = -1.
Titik Puncak = (2, -1).
